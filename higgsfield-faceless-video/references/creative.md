# Plan a faceless production

Choose a visual identity, narrative type and rendering mode from the user's request. A single illustrated explanation and a recurring channel episode use the same explainer approach; do not force fast montage on diagrams. For history/documentary, research the subject and use a clear chronological or causal arc. For storytelling, keep character identity and story continuity. For children, use age-appropriate language and visible character reactions. A sung children's video is a separate mode in `references/song.md`.

Build a style description that remains stable across generated assets. If the user selects a catalog preset, resolve the live preset instead of embedding an ID; if the user supplies an image, confirm whether it is a style reference, a character to preserve, or a presenter photo. A style reference does not authorize copying its people, logos or composition. Preserve a requested mascot's distinctive visual features. Do not animate an unmodified real photo as an illustrated background.

Create a roster for recurring characters, locations and important props. Generate each necessary reference with the style key and keep its actual job ID. Use the relevant reference images when generating scenes. For longer historical stories, plan chapters and era-specific character appearances; keep recognizable identity while changing age and costume. Warn about the time and cost of long runs before creating assets. Save the plan and completed job ledger so a later interruption does not require regenerating accepted assets.

For narrated motion, plan one idea and matching visuals per block. The illustrated explainer profile uses deliberate visual pacing and may use an exact shorter last block. For channel-oriented documentary or story videos, vary shot sizes and angles, locations, action and composition; keep adjacent shots distinct and make the visible scene illustrate what the narrator says. Do not use an over-the-shoulder shot unless the shoulder is actually in frame. Keep background dialogue out of separately narrated scenes.

Use the selected visual references consistently; check the first completed scene before generating the rest. Record named defects such as wrong aspect, identity drift or frozen motion. Retry failed or defective assets only; respect moderation refusals. Review the complete assembled video and audio, confirm requested subtitles and duration, and provide factual sources when applicable. A thumbnail can be offered or made when explicitly requested using `higgsfield-youtube-thumbnail`; do not fabricate an output if that skill or its tools are unavailable.
